개인정보처리방침

RowPilot은 데이터 처리 방식을 단순하고 투명하게 유지하는 것을 기본 원칙으로 설계되었습니다. 이 페이지에서는 앱이 사용하는 권한, 데이터의 종류, 저장 위치 및 제3자 제공 방침에 대해 설명합니다.

1. 개발자의 데이터 접근에 대하여

RowPilot은 온디바이스 처리를 기본 설계로 하며, 사용자의 훈련 데이터와 설정 등은 기기 내부 또는 사용자 본인의 클라우드 영역에서 관리됩니다.

훈련 기록, 위치 정보, 설정 정보, 연락처는 기기 내부(로컬 저장소) 보관을 기본으로 합니다. 팀 동기화 기능을 제외하고 개발자가 열람할 수 있는 서버로 데이터를 자동 전송하지 않습니다.

RowPilot의 소스코드는 오픈소스로 GitHub에 공개되어 있어 구현의 투명성을 보장합니다.

2. 요청하는 권한과 이용 목적

RowPilot은 다음 권한을 iOS에 요청합니다. 각각의 권한은 명시된 목적 이외에는 사용되지 않습니다.

위치 정보 (GPS)

RowMode에서의 속도 산출·이동 궤적 기록 및 SOS 기능에서의 긴급 메시지 작성에 사용합니다. GPS 좌표는 훈련 세션 중에만 수집되며 백그라운드에서 상시 추적하지 않습니다.

  • 수집 시점: RowMode 훈련 세션 중에만 수집
  • 저장 위치: 기기 내부
  • SOS 전송 시: SMS를 통해 사전에 설정한 긴급 연락처로 직접 전송
Bluetooth

Concept2 PM5 에르고미터와의 무선 연결에 사용합니다. 통신은 사용자의 iPhone과 PM5 기기 사이에서만 완결됩니다.

  • 연결 대상: Concept2 PM5 전용
  • 수집 데이터: 거리, 시간, 스트로크 레이트, 페이스 등 훈련 수치
모션 및 피트니스 센서

RowMode에서의 스트로크 레이트 감지에 사용합니다. 센서 데이터는 계측 처리에만 이용됩니다.

  • 수집 시점: RowMode 훈련 세션 중에만 수집
클라우드 동기화

Team 이상 요금제에서 팀이 생성되고 해당 팀에 가입한 사용자가 팀 동기화를 활성화한 경우, 팀의 훈련 수치 데이터가 개발자가 관리하는 외부 서버(Cloudflare D1)에 저장됩니다. 저장되는 데이터에 대한 자세한 내용은 제5절을 참조해 주세요.

  • 대상 사용자: Team·MAX 요금제의 팀에 소속된 사용자
  • 저장 내용: 훈련 수치 통계 및 앱 내 사용자 ID
SOS 연락처

사용자가 수동으로 등록한 긴급 연락처(전화번호·사용자 이름)는 기기 내부에 저장됩니다. SOS 메시지 전송에는 메시지 앱(SMS/MMS)을 사용합니다.

3. 데이터의 저장 위치 및 관리

RowPilot이 다루는 데이터의 저장 위치는 다음과 같습니다:

데이터 종류 저장 위치 개발자 접근
훈련 기록 (수상) 기기 내부 / 개인 iCloud 불가
훈련 기록 (에르고미터) 기기 내부 / 개인 iCloud 불가
GPS 궤적·위치 좌표 기기 내부 / 개인 iCloud 불가
SOS 연락처 기기 내부 불가
앱 설정 기기 내부 / 개인 iCloud 불가
팀 관리 데이터 (Team 이상) Cloudflare D1 (수치만) 수치만※

※ 팀 요금제의 동기화 서버에 저장되는 것은 훈련 수치(거리·시간·스트로크 레이트 등)뿐입니다. GPS 좌표나 이동 궤적은 포함되지 않습니다. 자세한 내용은 제5절을 참조해 주세요.

4. 사용자 간 데이터 공유

RowPilot에는 사용자 간에 훈련 데이터를 공유하는 기능이 있습니다. 공유는 Apple의 AirDrop(기기 간 P2P 직접 통신)을 통해 이루어집니다. 중계 서버를 거치지 않으므로 제3자 서버에 불필요한 데이터가 보관되지 않습니다.

AirDrop 통신은 Apple이 제공하는 종단간 암호화로 보호되며, 데이터를 수신할지 여부는 사용자가 매번 명시적으로 승인합니다.

5. 팀 요금제의 서버 동기화

Team·MAX 요금제에서는 여러 멤버의 데이터를 동기화하기 위해 개발자가 관리하는 외부 서버(Cloudflare D1)를 사용합니다.

서버에 기록되는 데이터:

  • 훈련 수치 (거리, 시간, 스트로크 레이트, 페이스, 파워 등)
  • 팀 멤버 식별 정보 (앱 내 사용자 ID 및 표시 이름)
  • 웹 코치 초대 기능을 이용하는 경우에 한하여, 팀 관리자가 명시적으로 등록한 웹 코치의 로그인용 이메일 주소 및 인증 해시

서버에 기록되지 않는 데이터:

  • GPS 좌표·이동 궤적 (수상 훈련 위치 정보)
  • SOS 연락처
  • 일반 멤버의 Apple ID나 이메일 주소 등 개인 식별 정보

6. 구매 및 결제 처리에 대하여

RowPilot Premium 정기 구독은 Apple의 StoreKit 2를 통해 처리됩니다.

  • 결제 정보(신용카드 번호 등)는 Apple이 보호·관리하며 개발자에게는 일절 공유되지 않습니다
  • 개발자가 전달받는 정보는 ‘구매 성사 여부’뿐입니다
  • 구독 관리 및 해지는 App Store 구독 설정에서 직접 진행하실 수 있습니다
  • 인앱 결제 관련 문의 및 환불 요청은 Apple 지원으로 문의해 주세요

7. 제3자 서비스 연동

현재 시점에 RowPilot이 사용하는 제3자 서비스는 다음과 같습니다:

일본 기상청 조석 데이터 API

조석 탭의 조석 그래프 표시를 위해 일본 기상청이 공개하는 조석 예측 데이터를 가져옵니다. 이 API 호출에는 사용자의 개인정보가 일절 포함되지 않습니다.

Cloudflare, Inc. (Cloudflare D1)

Team·MAX 요금제에서의 팀 데이터 동기화를 위해 Cloudflare사의 D1(서버리스 데이터베이스)을 사용합니다. 동기화되는 데이터에 대한 자세한 내용은 제5절을 참조해 주세요.

Strava 연동 (준비 중)

향후 Strava와의 훈련 데이터 연동 기능을 제공할 예정입니다. 이 기능은 명시적인 사용자 인증(OAuth)이 필요하며, 사용자의 동의 없이 데이터가 연동되는 일은 없습니다. 구현 시 본 방침을 업데이트할 예정입니다.

광고 SDK나 행동 추적을 위한 외부 라이브러리(Google Analytics, Firebase Analytics 등)는 사용하지 않습니다. 사용자의 행동 데이터를 추적하거나 분석하지 않습니다.

8. 본 방침의 변경에 대하여

RowPilot의 기능 추가나 법령 변경에 따라 본 개인정보처리방침을 업데이트할 수 있습니다.

  • 변경 시에는 페이지 상단의 ‘최종 업데이트일’을 갱신합니다
  • 사용자의 데이터 처리에 큰 영향을 미치는 변경의 경우 앱 내 알림 또는 고객지원 페이지를 통해 안내합니다
  • 변경 후에도 계속해서 앱을 이용하시는 경우 변경된 방침에 동의한 것으로 간주합니다

9. 준거법 및 관할

본 개인정보처리방침은 일본국 법률에 준거하여 해석됩니다. 본 방침과 관련하여 분쟁이 발생한 경우 개발자의 주소지를 관할하는 법원을 제1심 전속적 합의 관할 법원으로 합니다.
