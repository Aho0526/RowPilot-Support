v1.0.2 更新公告及全方案首月免费未生效致歉与退款说明

在介绍 RowPilot v1.0.2 新增功能与改进的同时，我们就此前所有付费方案均未能生效首月免费试用的问题诚挚致歉，并向符合条件的用户说明退款办理方式。

发布日期：2026年11月21日

感谢您一直以来的支持与使用。现将本次首月免费试用异常的致歉与退款安排，以及 v1.0.2 的新增功能和改进内容公告如下。

1. 关于首月免费试用未生效的致歉与退款说明

此前应用内订阅页面虽展示有“首月免费”“首次订阅免费1个月”等提示，但经核查确认，Pro、Manager、Team 与 MAX 的所有付费方案均未实际生效1个月免费试用。由此给各位用户带来的困扰与不便，我们深表歉意。

在 v1.0.2 中，已改为通过 StoreKit 2 动态检查首月免费优惠的适用资格，仅在确实配置并符合免费试用条件的方案上显示相应提示。

退款适用对象 2026年11月20日订阅 Manager 方案的用户
退款方式 银行转账 或 PayPay 转账汇款
退款申请流程
凡于 2026年11月20日订阅了 Manager 方案的用户，请发送邮件至客服邮箱 rowpilot.jp@gmail.com 并附上以下信息。核实后我们将尽快为您安排汇款退款。
  • 可确认订阅日期与时间的 Apple 收据邮件或购买凭证截图
  • 希望使用的退款方式：银行转账 或 PayPay
  • 收款账户信息：选择银行转账请提供银行名称、支行名称、账户类型、账号及户名；选择 PayPay 请提供 PayPay ID 或绑定手机号码

2. 新增功能

新增 BLE 心率传感器直接配对、心率与卡路里记录图表展示以及应用内服务器账号删除功能。

BLE 心率传感器直连与全模式心率监测

新增标准 BLE 心率传感器直连页面，支持自动重连与电量显示。结合自动读取已连接至 PM5 的心率带数据，可在水上 RowMode、Practice 及 Manager Mode 全模式下实时监测心率。

心率与消耗卡路里保存及图表可视化

支持保存平均心率、最高心率及卡路里消耗，并同步至本地训练详情、团队记录详情及 CSV 导出文件。训练图表页面新增心率图表标签页，并优化了图表曲线绘制效果。

应用内删除服务器账号与共享数据

在设置页面新增服务器账号删除功能，可直接删除服务器端的个人资料、团队成员关系及已上传的团队训练记录，设备本地保存的训练记录将继续保留。

3. 变更与改进

进一步强化 PM5 通信稳定性、规格校验、团队分页加载、数据一致性与安全防护。

PM5 通信稳定性、规范校验与断连保护

在 Practice Mode 引入顺序 CSAFE 发送队列，完善标准帧字节填充并优化 NFC 连接流程。时间、分段、间歇、卡路里及最多 50 段上限均已严格匹配 Concept2 PM5 规范，并新增中途断连时的进度保存提示。

Manager 仪表盘与竞速视图改进

仪表盘新增保存按钮与可变间歇进度显示；竞速视图补充返回与保存按钮、防误触锁定联动、同距离耗时排名及横竖屏旋转控制，采样频率改为 1 Hz / 2 Hz / 4 Hz 分段选择。

团队记录分页加载、权限与界面梳理

团队训练记录支持每次 500 条分页加载并提升对异常数据的容错能力。向普通成员开放成员列表与 Web 登录审批入口，精简重复设置项，将申请审批轮询缩短至 30 秒，并严格限定仅 Manager 角色共享对应权限。

离线同步、iCloud 恢复与记录一致性增强

将团队待传队列迁移至轻量化文件存储，避免外部导入记录被误传或已删除记录从 iCloud 恢复。同时优化多设备 Keychain 身份同步竞争、编辑取消还原以及已保存记录分享逻辑。

订阅资格判定与安全性升级

新增免费试用资格动态检测、退款及失效状态服务器同步、认证请求串行化、更严格的 Apple JWS x5c 证书链验证与 CSV 公式注入转义，并彻底清理旧版 Organization 方案残留定义。

RowMode、SOS 警报、潮汐与天气稳定性提升

将 SOS 警报停止横幅提升至全标签页顶层全局显示，并改为仅在鸣响期间激活音频会话。优化 RowMode 后台返回待机与暂停取消逻辑，统一潮汐计算至日本标准时间并在切换最近站点时立即刷新。
