隐私政策

RowPilot 以精简、透明地处理用户数据为核心设计原则。本页面详细说明应用所请求的系统权限、数据类型、存储位置以及第三方共享规则。

1. 关于开发者的数据访问权限

RowPilot 采用设备端本地处理为核心架构，用户的训练记录与应用设置均保存在设备本地或用户本人的个人云空间中。

训练记录、定位信息、偏好设置及紧急联系人均以设备本地存储为基础。除团队同步功能外，应用不会将任何数据自动上传至开发者可查阅的服务器。

RowPilot 的源代码已在 GitHub 上开源公开，全面确保代码实现与数据处理的透明度。

2. 所获取的权限及其用途

RowPilot 会向 iOS 系统申请以下权限，各项权限仅用于下述明确说明的用途，绝不挪作他用。

位置信息（GPS）

用于在 RowMode 中计算船速、记录航行轨迹，以及在紧急 SOS 功能中生成求助短信内容。GPS 坐标仅在训练进行期间采集，不会在后台进行全天候持续追踪。

  • 采集时机：仅限 RowMode 训练进行期间
  • 存储位置：设备本地
  • 发送 SOS 时：通过系统短信（SMS）直接发送至用户预先设置的紧急联系人
蓝牙（Bluetooth）

用于与 Concept2 PM5 划船测功仪建立无线连接。全部通信均在用户的 iPhone 与 PM5 设备之间直接完成。

  • 连接对象：仅限 Concept2 PM5
  • 获取数据：划行距离、时间、桨频（SPM）、配速等训练数值
运动与健身传感器

用于在 RowMode 中检测划桨动作并计算实时桨频。传感器数据仅用于本地测算处理。

  • 采集时机：仅限 RowMode 训练进行期间
云端同步

当在 Team 及以上方案中创建团队，且加入该团队的成员开启团队同步后，团队的训练数值统计数据将保存在由开发者管理的外部服务器（Cloudflare D1）中。关于所保存数据的具体内容，请参阅第 5 节。

  • 适用对象：隶属于 Team 或 MAX 方案团队的用户
  • 保存内容：训练数值统计数据及应用内用户 ID
SOS 紧急联系人

用户手动登记的紧急联系人信息（电话号码与使用者姓名）仅保存在设备本地。SOS 求助消息通过系统自带的“信息”应用（SMS/MMS）发送。

3. 数据的保存位置与管理

RowPilot 所处理各类数据的存储位置及访问权限如下表所示：

数据类型 保存位置 开发者访问权限
训练记录（水上实船） 设备本地 / 个人 iCloud 不可访问
训练记录（陆上测功仪） 设备本地 / 个人 iCloud 不可访问
GPS 轨迹与位置坐标 设备本地 / 个人 iCloud 不可访问
SOS 紧急联系人 设备本地 不可访问
应用设置 设备本地 / 个人 iCloud 不可访问
团队管理数据（Team 及以上） Cloudflare D1（仅限数值） 仅限数值 ※

※ 团队方案同步服务器上仅保存训练统计数值（距离、时间、桨频等），绝不包含 GPS 坐标或水上航行轨迹。详情请参阅第 5 节。

4. 用户之间的数据分享

RowPilot 提供在用户之间分享训练记录的功能，分享过程通过 Apple 的 AirDrop（设备间点对点直接通信）完成。由于不经过任何中转服务器，数据不会被留存在任何第三方服务器上。

AirDrop 通信全程受 Apple 端到端加密保护，且每次接收均需由接收方本人明确点击确认。

5. 团队方案的服务器同步

在 Team 与 MAX 方案中，为实现多名队员之间的数据汇总同步，应用使用由开发者管理的外部数据库服务（Cloudflare D1）。

记录在服务器上的数据：

  • 训练统计数值（距离、用时、桨频、配速、功率等）
  • 团队成员标识信息（应用内用户 ID 及显示名称）
  • 仅在使用 Web 教练邀请功能时：由团队管理员明确登记的 Web 教练登录邮箱地址及认证哈希值

不会记录在服务器上的数据：

  • GPS 坐标与移动轨迹（水上训练的地理位置信息）
  • SOS 紧急联系人
  • 普通成员的 Apple ID、电子邮箱等个人身份识别信息

6. 购买与支付处理

RowPilot Premium 自动续期订阅全程通过 Apple 的 StoreKit 2 处理。

  • 支付信息（信用卡号等）由 Apple 严格保护与管理，绝不会向开发者共享
  • 开发者仅能获知“订阅交易是否生效”的状态信息
  • 管理或取消订阅可在 App Store 的订阅设置中随时操作
  • 有关应用内购买的争议或退款申请，请直接联系 Apple 官方支持

7. 第三方服务集成

目前 RowPilot 所调用的第三方服务如下：

日本气象厅 潮汐数据 API

用于在潮汐标签页展示潮汐变化曲线，获取日本气象厅公开的潮汐预测数据。该 API 请求不包含任何用户个人信息。

Cloudflare, Inc. (Cloudflare D1)

用于在 Team 与 MAX 方案中同步团队数据，采用 Cloudflare 公司提供的 D1 无服务器数据库。关于同步数据的具体范围，请参阅第 5 节。

Strava 联动（筹备中）

我们计划在未来支持与 Strava 同步训练数据。该功能必须经过用户本人的明确授权（OAuth），未经用户同意绝不会同步任何数据。功能正式上线时我们将同步更新本隐私政策。

本应用未接入任何广告 SDK 或用户行为追踪分析库（如 Google Analytics、Firebase Analytics 等），不对用户使用行为进行任何追踪或画像分析。

8. 本政策的变更

随着 RowPilot 新功能的推出或相关法律法规的修订，我们可能会适时更新本隐私政策。

  • 政策更新时，将同步修改页面顶部的“最后更新日期”
  • 若变更内容对用户数据处理方式产生重大影响，我们将通过应用内通知或支持页面进行公告
  • 变更生效后您继续使用本应用，即视为您已阅读并同意更新后的隐私政策

9. 适用法律与管辖法院

本隐私政策的解释与适用均遵循日本国法律。如因本政策产生任何争议，均以开发者住所地有管辖权的法院作为一审专属合意管辖法院。
