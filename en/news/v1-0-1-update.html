Version 1.0.1 Released

v1.0.1 Update Released & Pro Plan Feature Expansion

RowPilot v1.0.1 is now live on the App Store. Alongside major new features and refinements across measurement, PM5 sync, and team management, the Pro plan gains new capabilities at the unchanged ¥200 JPY/month price.

Published: November 5, 2026 / Released: November 16, 2026

Thank you for using RowPilot. Version v1.0.1 has been approved and released on the App Store. Update your app to start using all of the new features and improvements detailed below.

1. New Features Added

The following capabilities have been newly introduced in v1.0.1:

Multilingual Support (6 New Languages)

Added support for German, French, Spanish, Italian, Simplified Chinese, and Korean, bringing total supported languages to 8 alongside Japanese and English.

Team Web Dashboard Integration

Connect with the PC/browser Team Web Portal to review team workouts, aggregate stats, and export CSV files. Supports custom team URL slugs, Web coach invitations, and one-tap app login approval via rowpilot://web-auth.

Team Workout Filtering & Batch Upload

Added keyword search (athlete name, notes, boat type) as well as athlete, type, and date-range filters for team workouts. Also added batch uploading to share past unuploaded local records all at once.

RowMode Motion Sensitivity & Portrait Battery

Added a Motion Sensitivity slider (0.03 G to 0.30 G) inside RowMode display settings to fine-tune stroke catch detection, plus a toggle to display battery status in portrait orientation.

Nationwide Tide Map & Water Threshold Line

Added an interactive map view to browse and preview tide curves across 239 observation stations nationwide, along with a configurable reference water-level threshold line on the tide chart.

Device Lock Reset & Guided Inquiry Form

Added admin tools to unlock device authentication for members switching devices, automatic approval polling for pending requests, and a confirmation-backed inquiry screen specifying the target page and element.

2. Changes & Improvements

Measurement accuracy, Bluetooth reliability, team infrastructure, and data sync have been significantly refined:

Unified Cloudflare D1 Team Backend

Retired legacy CloudKit team management in favor of Cloudflare D1. Organized advanced team settings, invite code regeneration, ownership transfer, team workout deletion, duplicate join-request prevention, offline retry queues, and edge-case handling.

PM5 Sync & Interval Progress Display

Optimized BLE command queue timeouts, polling resilience, and 20-byte CSAFE framing for Variable Intervals. Fixed fixed-interval command framing, prevented stale post-reset notifications, and added per-interval remaining distance/time and interval count indicators.

RowMode Detection, GPS & End Flow

Improved dynamic axis selection and auto-start conditions, decoupled real-time GPS accuracy display from distance filtering, renamed Stop to End, enabled save prompts for sessions under 10 seconds, and removed post-exit landscape lock.

Accurate Averages & Ghost Race Fixes

Saved records now compute true session averages (500m pace, SPM, and watts) instead of instantaneous end-of-session values across RowMode, Practice, and Manager Mode. Ghost Race timeline interpolation and finish detection were also fixed.

Rigging 2D / 3D View & Presets

Refined the 3D rigging diagram and touch controls, added bow-mounted wing and straight rigger selection with improved 2D/3D rendering accuracy, and standardized blade presets.

CSV Export, iCloud Sync & StoreKit Sync

Ensured lazily-loaded chart points, crew info, and GPS routes are resolved before CSV export and coordinated iCloud sync. Added JWS verification, foreground subscription status refresh, updated pricing, and Organization plan deprecation.

3. Pro Plan Feature Expansion & Unchanged Price

Starting with v1.0.1, the following features have been added to the Pro plan while keeping the price unchanged at ¥200 JPY / month.

Choose Tide Observation Points Nationwide

In addition to auto-detecting the nearest station via GPS, select and preview tide curves across 239 observation stations nationwide via map or list.

PM5 Workout Sync for up to 4 Machines

Connect up to 4 Concept2 PM5 rowing ergometers simultaneously via Bluetooth and batch-send workout menus for synchronized crew training.

Multi-Seat Crew Management

In addition to single sculls, create and manage multi-seat crew lineups from doubles to eights.

4. Pro Plan Feature Summary (v1.0.1)

All features included in RowPilot Pro after updating to v1.0.1:

  • All Free features (GPS rate meter, SPM real-time display, unlimited session history, emergency SOS)
  • PM5 connection up to 4 machines (expanded from 1-on-1 connection in Free; workout sync)
  • ForceCurve graph display (visualize stroke force curve)
  • Ghost Race mode (real-time racing against past records)
  • Choose and preview tide observation points nationwide via map
  • Multi-seat crew management (Double through Eight)
