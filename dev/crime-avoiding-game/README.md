# 犯罪回避ゲーム (Crime Avoidance Game)

ブラウザ上で動作する、2人対戦型のオンライン心理戦ゲームです。  
「相手の言葉は真実か、それとも罠か？」——チャットでの駆け引きと情報の非対称性を駆使して相手を出し抜きます。  
また、SNSやメッセージアプリ等で知らない相手とやり取りする際の危険性を疑似体験できる**教育的防犯教材**としての側面も備えています。

---

## 🎯 ゲームコンセプト & ルール

### 1. 目的（非対称対戦）
- **被害者側（逃走）**: 犯罪者との接触を避け、目的地（安全地帯・避難所 🏁）に到達するか、全ターン（12ターン）逃げ切れば勝利！
- **犯罪者側（追跡）**: 被害者と同じ交差点に到達（接触・確保）すれば勝利！

### 2. 1手ごとの心理戦（ターン制・同時提出システム）
「相手に関係なくズカズカ進めてしまう」のを防ぎ、チャット心理戦を最大限に楽しむための新システムです：
1. **① 移動先の選択**: 隣接する交差点をタップして、次の移動先を仮選択（📍ピン表示）。
2. **② チャットの入力**: 相手を惑わすウソや、居場所のヒントを入力（クイック定型文も使用可能）。
3. **③ 行動の確定**: 「行動を確定する！」を押して相手を待ちます。
4. **④ ターン解決**: 相手も移動先とメッセージを確定（D1に記録）すると、**双方が同時に移動し、チャットが更新され、次のターンの移動が許可**されます！

### 3. 情報の非対称性 (最重要システム)
- **ゲーム開始時のみ**: 最初の**3秒間だけ**、相手の初期位置がレーダーに表示されます。
- **ゲーム開始後**: 相手の現在地は完全に不可視になります。
  - APIレベルで相手の座標をマスクしているため、ブラウザのデベロッパーツール等による解析・チートも防止されています。
- **自分の位置と足跡**: 自分の現在地と過去の移動履歴はマップ上に表示されます。

### 3. チャット心理戦
- チャットは単なる会話ではなく、**相手の位置や意図を読み解くゲームシステム**です。
- 「今、駅の近くにいるよ」「反対側に逃げた」など嘘をついて相手を誘導したり、相手の発言の真偽を推理します。
- クイック定型文ボタンにより、スマートフォンやPCでも素早く心理戦を仕掛けられます。

### 4. 不審者ブロック＆削除（被害者専用機能）
- 被害者はチャット画面上部の「🛡️ 不審者をブロック＆削除する」を実行可能。
- 1人プレイ（AI対戦）時、AIは最初は被害者のGPS位置を完全把握して追い詰めてきますが、**ブロックを実行すると追跡が遮断され、AIは位置をロスト**します。
- 「不審な相手をブロックして距離を置く」というネットリテラシーの基本をゲーム内で体感できます。

### 5. ゲーム終了後の答え合わせ（振り返りリプレイ）
- ゲーム終了後、隠されていた全情報が公開されます！
- **リプレイシークバー**: 時間をスライダーで巻き戻し/再生し、マップ上で両者の動きや最接近の瞬間を確認可能。
- **チャット真偽検証**: 各発言をクリックすると、「その発言があった瞬間に実際はお互いどこにいたのか」がマップ上に可視化されます。
- **防犯の学び**: 「なぜ相手の言葉を信じてしまったのか」「どこでブロックすべきだったか」を振り返ることができます。

## 🚀 遊び方・動作確認

### A. ローカルで遊ぶ場合（即座に対戦・テスト可能）
特別なサーバー環境のデプロイなしで、今すぐブラウザ単体で遊べます！

1. ブラウザで `http://localhost:8000/dev/crime-avoiding-game/` を開きます。
2. **1人プレイ（AI対戦）**:
   - 「🤖 AI犯罪者と対戦」タブを選び、「AI対戦をスタート！」をクリック。
3. **2人対戦（ブラウザ2タブ対戦 / PC同士）**:
   - タブ1で「ルームを新しく作成」→ 発行されたルームコード（例: `A8B2`）をコピー。
   - タブ2で「発行されたルームに参加」→ ルームコードを入力して参加。
   - タブ1の「ゲームを開始する！」を押すと、両画面が同時に対戦開始！
   - ※ `BroadcastChannel` と `localStorage` により、リアルタイムに通信・マスキングが行われます。

### B. Cloudflare Workers + D1 にデプロイする場合
1. Cloudflare D1データベースを作成:
   ```bash
   npx wrangler d1 create crime_avoiding_db
   ```
2. 出力された `database_id` を `wrangler.toml` に設定。
3. スキーマを適用:
   ```bash
   npx wrangler d1 execute crime_avoiding_db --file=./schema.sql
   ```
4. Workers をデプロイ:
   ```bash
   npx wrangler deploy
   ```
5. デプロイ先のURL（例: `https://crime-avoiding-game.yourname.workers.dev`）を、ゲーム画面右上の「⚙️ 接続設定」に入力すれば本番環境で全国どこからでもオンライン対戦できます。
