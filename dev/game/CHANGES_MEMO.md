## 主な変更点 & バグ修正まとめ

### 1. キャンバスの縦横比潰れ（アスペクト比歪み）の完全修正
- **問題点**:
  - 画面高が低い端末（タブレット等）で `max-height` を適用した際、幅が強制的に引き伸ばされてグリッドやキャラクターが横長にペッタンコに潰れていた。
- **改善後**:
  - `#gameCanvas` に `width: auto; height: auto; max-width: min(744px, 94vw); max-height: 54vh; aspect-ratio: 496 / 324;` を適用。
  - 幅・高さどちらで縮小されても、**正方形のグリッドマス目とキャラクターのプロポーションが1ピクセルも崩れずに美しく維持**されます。

### 2. 右端オレンジ壁の貫通バグの修正
- **問題点**:
  - ステージ4にて U, V, G, L などに配置してキャラクターが右端（col 4 の段差上）に到達した際、壁衝突の座標計算が `curX = COLS (5.0)` まで歩かせていたため、オレンジ色の壁の境界線を越えて壁の中にめり込み・突き抜けてしまっていた。
- **改善後**:
  - スティックマンの身体幅（右端まで約10px）を考慮し、右壁衝突位置を `wallHitX = COLS - 0.65`（約4.35、col 4 の右寄りで鼻先が壁境界にピタッと触れる位置）に修正。
  - 壁を貫通することなく、**境界線手前でコツンと衝突してスタックし、即座にミス判定→リスポーン**するようになりました。

### 3. 地面歩行の維持 & 壁・障害物スタック時の「即時アウト」判定
- **挙動の整理**:
  - **地面（最下段）**: 最下段（row 4）は地面（草・土）に足が着いているため、ブロックがなくても通常通り歩行可能。
  - **右端の壁（オレンジ色）**: 右端に進んだ際、ゴールマス以外の高さにあるオレンジ色の壁に衝突すると、その瞬間に即座にゲームオーバー（ミス）となり、待たずにリスポーンします（以前のように壁を抜けて画面外に落ちるのを待たない）。
  - **障害物スタック**: 前方にジャンプできないブロック壁や天井があり進めなくなった場合も、その場で即座にミス判定となります。
  - **右壁の視覚化**: ゴールマス以外の右端境界線にオレンジ色（`#ff9800`）の壁ラインを描画。

### 4. 「ｼｭｩｲｰﾝ」自動リスポーン演出（速度・余韻調整済み）
- **改善後**:
  - ゲームオーバーになった瞬間、キャラクターが光のオーブ（粒子＋キラキラトレイル）に変化し、「ｼｭｩｲｰﾝ」と滑らかな放物線軌道を描いてスタート位置へ戻る。
  - **速度調整**: 移動時間を約0.85秒に設定し、光の粒子の余韻を残すことで、視覚的に心地よく追従できるスピードに調整。
  - 到着時にスタート前のブロック配置が**自動復元**され、すぐに次の試行を行える。

### 13. ブロック連結性（ひっつき）ルールの導入、青矢印×緑矢印の1マス移動修正、ステージ11・15の正解データ修正
1. **ブロック連結性（ひっつき）ルールの導入（ステージ7等の抜け道完全防止）**:
   - **仕様**: 2個以上のブロックを配置する場合、すべてのブロックが**縦・横・斜め（8近傍）のいずれかで隣接して一続きの塊（連結成分 = 1つ）**になっている必要がある（離れ小島のように孤立したブロックがあるとスタート不可）。
   - **理由**: ステージ7のように「紫枠に1個、ゴール前に離れて1個」といった2ブロックの抜け道クリアを根絶し、パズルの本来の解法を強制する。※ステージ7の公式解答自体が斜め隣接で構成されているため、8方向隣接判定を採用。
   - **操作フィードバック**: 配置中、ブロック同士が離れている場合はステータスバーに「⚠️ ブロック同士をくっつけて配置してください」と案内し、スタートボタンを押した際も警告を出してスタートを阻止。
2. **青矢印×緑矢印の連携挙動を「1マスのみ動く」へ修正**:
   - 青矢印（端までダッシュ）に乗ったブロックが移動経路上で緑矢印（ステップ）を踏んだ際、**緑矢印の方向に向きを変え、そこから「1マスのみ動いて停止」**するように修正（緑矢印本来の1マス移動ルールに即した動作）。
3. **ステージ11 & ステージ15の正解データ修正（Canva原本全照合済み）**:
   - **ステージ11**: 正解マスが誤って Oマス（`col: 3, row: 1`）となっていたのを、原本通りの **Pマス（`col: 4, row: 1`）** へ修正。
   - **ステージ15**: `forbidden` に誤って含まれていた `{ col: 0, row: 3 }` を除去し、原本通り正解データ（L字型 6ブロック）に Hマス（`col: 0, row: 3`）を追加。
### 14. 小画面でのステージ潰れ（アスペクト比歪み）の完全解消 & ホーム画面ボタンのブロック世界観デザイン刷新
1. **小画面・低画面時におけるステージ（キャンバス）の潰れ・アスペクト比歪みの根絶**:
   - **原因**: `#gameCanvas` のCSSにおいて、幅が `min(880px, 60vw)` や `min(94vw, 680px)` などの横幅優先で指定されていたため、画面の高さが低い端末（ノートPCやタブレット、ウィンドウ縮小時）で `max-height` に制限された際に、幅が自動で縮小されず、キャンバスの縦横比（496:324）が狂って上下に押しつぶされて横長ペッタンコになる現象が発生していた。
   - **改善**: 通常時および全メディアクエリブレークポイント（1200px以上、980px以下、740px以下、600px以下）において、幅の計算式に `calc((上限高さ) * (496 / 324))` を組み込み（例: `width: min(880px, 60vw, calc((100vh - 120px) * (496 / 324)))`）、常に「高さ上限 × 496/324」を上限幅とすることで、どんな極端な画面サイズやアスペクト比の端末でも、ステージのマス目（1:1）が1ミリも歪まずに完璧な比率で美しく維持されるよう修正。
2. **ホーム画面ボタンのブロックゲーム風（立体3Dボクセルブロック）デザイン刷新**:
   - **改善内容**:
     - 単なるツルッとしたフラットグラデーションを廃止し、ゲーム内のハコやレンガと呼応する立体3Dボクセルブロックデザインへ大幅刷新。
     - **ブロック形状 & ベベル立体加工**: 上面と左面にハイライト面（`inset 4px 4px 0 ...`）、底面と右面にディープシャドウ（`inset -4px -4px 0 ...`）を施し、外枠に `3.5px solid #000` と `0 7px 0 #000` のブロック押し出し影を付与。
