Version 1.0.1 Released

v1.0.1アップデート配信のお知らせとProプラン機能拡充について

RowPilot v1.0.1 が App Store にて公開されました。新機能の追加および各機能の大幅な改善に加え、Proプランの月額200円据え置きと機能拡充を実施しています。

公開日: 2026年11月5日　/　配信開始: 2026年11月16日

日頃よりRowPilotをご利用いただきありがとうございます。このたび、最新バージョン v1.0.1 の配信を開始いたしました。App Store よりアップデートいただくことで、以下の新機能および各種改善をご利用いただけます。

1. 新たに追加された機能

多言語対応やPCブラウザ連携、チーム運用機能を中心に、以下の機能を追加しました。

6言語の多言語対応

ドイツ語、フランス語、スペイン語、イタリア語、簡体字中国語、韓国語に新たに対応し、日本語・英語を含む計8言語でアプリをご利用いただけます。

Team Web ダッシュボード連携

PCやタブレットのブラウザからチーム記録の確認・集計・CSV出力が行えるWebポータルに対応しました。専用URLスラッグの設定、Webコーチの招待管理、アプリからのワンタップログイン承認が可能です。

チーム記録の絞り込みと一括送信

チームワークアウト一覧に選手名・メモ・艇種でのキーワード検索や種別・期間フィルタを追加しました。端末内に保存された過去の未共有ワークアウトをまとめてチームへ送信する一括アップロードにも対応しています。

RowMode モーション感度と表示設定

RowModeの表示設定内にモーション感度調整スライダーを追加し、検知閾値を0.03 G〜0.30 Gの範囲で調整できるようになりました。縦画面でのバッテリー残量表示の切り替えにも対応しています。

全国潮位マップ選択と基準水位ライン

全国239地点の潮位観測所を日本地図のピンから選択し、グラフプレビューを確認できるマップ画面を追加しました。設定した基準水位を潮位グラフ上にライン表示する機能も追加しています。

端末認証ロック解除と確認付き問い合わせ

機種変更時などに発生する端末認証ロックをチーム管理者が解除できる機能や、参加申請中の自動承認チェック、対象画面や要素を指定して確認できるお問い合わせフォームを追加しました。

2. 変更・改善された点

計測精度やBluetooth通信、チーム基盤、データ同期の安定性を大幅に向上させました。

チーム管理基盤の刷新と安定性向上

旧CloudKitベースのチーム管理を廃止し、Cloudflare D1へ完全一本化しました。詳細設定シートの整理、招待コード再生成、オーナー権限移譲、チーム記録削除、参加申請の二重送信防止、オフライン時の自動再送を整備し、プラン移行や権限管理の例外処理も安定化しています。

PM5 通信・インターバル表示の改善

送信キューのタイムアウト処理や状態ポーリングを最適化し、Variable Interval送信のCSAFE分割フレームを仕様に完全適合させました。固定インターバル設定の修正やリセット直後の旧通知遮断に加え、実行中の区間別残り距離・残り時間・完了インターバル数表示に対応しています。

RowMode 計測・GPS表示・終了フロー見直し

動的軸選択と自動スタート判定を見直し、距離フィルタから独立したリアルタイムGPS精度表示に対応しました。終了ボタン表記を「End」へ変更し、10秒以下の計測でも保存確認を表示するよう改善するとともに、終了時の横画面ロックを廃止しています。

ワークアウト平均値とゴーストレース修正

ワークアウト保存時に終了直前の瞬間値ではなく、水上RowMode・Practice・ManagerModeの全モードでセッション全体の正確な平均500mペース・平均SPM・平均ワットが記録されるよう改善しました。ゴーストレースでも開始時の補間とゴール判定を修正しています。

リギング 2D / 3D ビューと設定の刷新

リギング設定画面の3Dビュー微調整に加え、ボウマウント・ウイングリガーとストレートリガーの選択対応、2D/3D図面の描画位置や精度の改善、ブレードプリセットの整理を実施しました。

CSV書き出し・iCloud同期・課金状態同期

CSV書き出しやiCloud同期時に遅延ロード分のグラフデータ・クルー情報・GPSルートを確実に補完して安全に保存するよう修正しました。またStoreKit 2のJWS検証連携、アプリ復帰時の契約状態自動更新、料金改定およびOrganizationプラン廃止をアプリ内へ反映しています。

3. Proプランの機能拡充と価格据え置き

v1.0.1より、Proプランに以下の機能を追加・拡充しました。月額料金は10月1日の改定後価格である月額200円のまま据え置きとし、追加料金なしでご利用いただけます。

全国239地点の潮位観測所を任意選択

GPSによる最寄り観測所の自動表示に加え、全国239地点の気象庁潮位観測所からマップや一覧で任意の地点を自由に選択し、遠征先や大会会場の干満時刻と潮位グラフを事前に確認できます。

最大4台までのPM5同時メニュー送信

Concept2 PM5ローイングエルゴとの接続において、最大4台までの同時接続およびトレーニングメニューの一括送信に対応します。4人乗りクルーの同期トレーニングがProプラン単体で実現します。

複数人クルー編成・管理

シングルスカルに加えて、ダブルスカルからエイトまでの複数人クルー編成・管理機能をご利用いただけるようになりました。

4. v1.0.1アップデート後のProプラン機能一覧

v1.0.1へアップデートすることで、以下の機能がすべてProプランでご利用いただけます。

  • Free の全機能（GPS計測、SPMリアルタイム表示、無制限セッション履歴、緊急SOSなど）
  • 最大4台までのPM5接続（Freeの1台接続から拡張・メニュー送受信）
  • ForceCurveグラフ表示（ストロークの力曲線可視化）
  • ゴーストレース機能（過去記録とのリアルタイム対戦）
  • 全国の潮位観測所から任意選択・マップ事前確認
  • 複数人クルー編成・管理（ダブル〜エイト対応）
