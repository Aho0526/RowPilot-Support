Version 1.0.2 / Important Notice

v1.0.2アップデートのお知らせと初回1ヶ月無料表示に関するお詫び・返金のご案内

RowPilot v1.0.2 のアップデート内容のご案内とあわせて、すべての有料プランで初回1ヶ月無料トライアルが適用されていなかった不具合に関するお詫びおよび対象者様への返金対応についてお知らせいたします。

公開日: 2026年11月21日

日頃よりRowPilotをご利用いただきありがとうございます。このたび、最新バージョン v1.0.2 のご案内とともに、サブスクリプション画面の初回無料表示に関するお詫びと返金対応、ならびに各種機能追加・改善点をお知らせいたします。

1. 初回1ヶ月無料トライアルに関するお詫びと返金のご案内

これまでアプリ内のサブスクリプション画面において「初月無料」と案内しておりましたが、Pro、Manager、Team、MAX のすべての有料プランに対して1ヶ月無料トライアルの効果が適用されていなかったことが判明いたしました。ご利用の皆様に多大なるご迷惑とご心配をおかけしましたことを、心よりお詫び申し上げます。

v1.0.2 では初回無料オファーが設定されており、かつ適用対象となるプランにのみ無料表示を行うよう修正いたしました。

返金対象者 2026年11月20日に Manager プランをご契約いただいた方
返金方法 銀行振込 または PayPay による送金
返金のお手続き方法
2026年11月20日に Manager プランをご契約いただいたお客様は、サポート窓口 rowpilot.jp@gmail.com まで以下の情報をお添えのうえご連絡ください。確認後、速やかに送金手続きを行います。
  • ご契約日時が確認できる Apple からの領収書メール等のスクリーンショット
  • 返金方法：銀行振込 または PayPay
  • 返金先情報：銀行振込をご希望の場合は金融機関名・支店名・口座種別・口座番号・口座名義、PayPay をご希望の場合は送金先の PayPay ID またはご登録電話番号

2. 新たに追加された機能

心拍センサーの直接連携と計測データの可視化、アカウント削除機能を追加しました。

BLE 心拍センサー直接接続と全モード心拍計測

標準 BLE 心拍センサーを iPhone へ直接接続できる専用画面を追加し、自動再接続やバッテリー残量表示に対応しました。PM5 に接続された心拍計の自動読み取りとあわせて、水上 RowMode・Practice・Manager Mode の全モードでリアルタイム計測が可能です。

心拍数・消費カロリーの記録保存とグラフ可視化

平均心拍数・最大心拍数および消費カロリーの記録保存に対応し、ワークアウト詳細画面、チーム記録詳細、CSV 書き出しへ反映しました。ワークアウトグラフ画面にも心拍数グラフタブを追加し、グラフの描画精度も改善しています。

アプリ内からのサーバーアカウント削除機能

設定画面にサーバーアカウント削除機能を追加しました。サーバー上のユーザー情報、チーム所属、チームへ共有済みの記録をアプリ内から削除できます。端末ローカルに保存されたワークアウト記録はそのまま残ります。

3. 変更・改善された点

PM5 通信や仕様準拠の入力制御、チーム記録の読み込み、認証・セキュリティと各モードの安定性を強化しました。

PM5 通信安定化と仕様準拠の入力制限・切断保護

Practice Mode に順次 CSAFE 送信キューを導入し、標準フレームのバイトスタッフィング厳密化や NFC 接続フローの安定化を行いました。時間・スプリット・インターバル・最大50区間の設定範囲を Concept2 PM5 仕様に準拠させ、ワークアウト中に接続が切れた際もそこまでの記録を保存できるアラートを追加しています。

Manager Mode ダッシュボードとレースビュー改善

ダッシュボードへ保存ボタンと可変インターバルの進行表示を追加し、レースビューにも終了・保存ボタン、誤操作ロック連携、同距離時の経過時間による順位判定、画面回転制御を導入しました。データ取得周期の設定も 1 Hz・2 Hz・4 Hz の選択式へ見直しています。

チーム記録のページネーションと権限・導線整理

チーム記録一覧で500件ごとの追加読み込みに対応し、欠損レコードが含まれても一覧表示が崩れないよう堅牢化しました。一般メンバー画面へのメンバー一覧・Web ログイン承認ボタンの配置、設定画面の重複整理、参加申請確認の30秒短縮、Manager 機能共有対象の Manager ロール限定化も実施しています。

オフライン同期・iCloud 復元・記録整合性の強化

チーム送信待ちキューをファイル保存へ移行して軽量化し、外部インポート記録の誤送信や削除済み記録が iCloud から復活する事象を防止しました。複数端末間の Keychain 認証同期の競合対策や、記録詳細画面での編集キャンセル操作、保存済み確定データの共有整理も行っています。

サブスクリプション判定とセキュリティ強化

無料トライアル適格性の動的判定に加え、返金・失効状態のサーバー同期、並列認証の競合防止、Apple JWS 証明書チェーン検証の厳格化、CSV 出力時の数式インジェクション対策を実装しました。旧 Organization プラン定義の整理と個人契約表示の分離も完了しています。

RowMode・SOS 警報・潮位・天気の安定性向上

SOS 警報鳴動中の停止バナーを全タブ共通の最前面へ移設し、鳴動時のみ音声セッションを有効化するよう改善しました。RowMode のバックグラウンド復帰時の自動スタート待機制御や一時停止中キャンセル時の挙動修正、潮位計算の日本標準時統一と最寄り観測所切替時の自動更新も実施しています。
